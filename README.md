# なかよしキッチン

みんなで つくろう！ 1〜4にんで あそべる きょうりょく クッキングゲームです。iPad と iPhone で あそべます。

- **かかり**：ざいりょうがかり・きるがかり・やくがかり・レシピがかり。いくつでも えらべて、おなじ かかりに 2にん いじょうでも OK。だれも えらばない かかりは、みんなの がめんに でます。
- **おみせは 1しゅうかんごとに こうたい**（パンやさん → おすしやさん → ケーキやさん → ハンバーガーやさん）。ひとまわりすると「よるの」「おまつりの」「ゆきの」おみせに かわります。
- **ステージは むげん**：ステージばんごうから じどうで つくられ、すすむほど メニューが ふえます。
- **ログインなし**：「へやを つくる」で でる 4けたの あいことば（QR コードでも OK）で はいれます。ひとりでも あそべます（つうしん なし）。
- ほしを あつめると、コックさんの ぼうしが ふえます。

## しくみ

- 1つの `index.html` だけで うごきます（GitHub Pages で こうかい）。
- オンラインは たいアカウントと おなじ Firebase（tai-account）の Firestore `nakayoshiKitchen/{あいことば}` を つかいます。ホストの たんまつが ゲームを すすめ、ほかの たんまつは そうさを おくります。ホストが いなくなると、つぎに はいった ひとが ひきつぎます。
