# なかよしキッチン

協力クッキングゲーム。1〜4人、iPad・iPhone 対応。

## 係

| 係 | 内容 | 操作 |
| --- | --- | --- |
| 材料係 | 棚から材料を出す | 箱から送り口へドラッグ |
| 切る係 | まな板で切る | 連打（かたい材料ほど回数が多い） |
| 混ぜる係（ステージ3から） | ボウルで混ぜる | ボウルの上を指でぐるぐる |
| 焼く係 | 焼いて取り出す | 待ちからコンロへドラッグ、完成したら長押しで取り出し（放置すると焦げる） |
| 渡す係 | 盛り付けて渡す | 完成品をお皿へドラッグ、できた料理をお客へドラッグ |
| 飾る係（ステージ7から） | 料理を仕上げる | 大きい丸から点を順になぞる（きれいだとコイン増） |
| 洗う係（ステージ5から） | お皿を洗う | 汚れたお皿を左右にゴシゴシ（きれいなお皿がないと盛り付け不可） |

- 係は複数選択可。同じ係に複数人も可。
- 誰も選ばない係は、係の少ない人へ自動で割り当て。
- 混ぜる・洗う・飾るは、部屋の画面でホストが ON/OFF を選べる。
- ステージ1から「切る」「焼く」の両方が必要なメニューが出るため、全員に仕事がある。

## 店とステージ

- 店は3日ごとに交代（パン屋 → すし屋 → ケーキ屋 → バーガー屋）。
- ステージは無限。番号から自動生成し、進むほどメニューとお客が増える。
- ★を集めると帽子が解放。

## オンライン

- ログイン不要。「部屋を作る」で出る4桁の合言葉（QR コード可）で参加。ひとりでも遊べる（通信なし）。
- たいアカウントと同じ Firebase（tai-account）の Firestore `nakayoshiKitchen/{合言葉}` を使用。ホストの端末がゲームを進行し、ホストが抜けると次の参加者が引き継ぐ。
